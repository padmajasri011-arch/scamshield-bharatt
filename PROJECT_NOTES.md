# 4-day build upgrade plan

## Day 1 — MVP
- Finish text classifier and UI.
- Add screenshots as an input mock.
- Create the final pitch story.

## Day 2 — Multimodal
- Add OCR (e.g. Tesseract or a hosted OCR API).
- Extract text from screenshots.
- Add URL reputation checks only from allowed/appropriate sources.

## Day 3 — Bharat-first
- Add Telugu/Hindi translation.
- Add a simple voice input/output path.
- Add low-bandwidth UI mode.

## Day 4 — Polish
- Add evidence/explanation cards.
- Add privacy messaging.
- Record 3–5 minute demo.
- Final testing and submission.
